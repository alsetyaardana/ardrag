Embedding

Some gateways cap the combined token count and/or raw request size across a whole batch, separately from the per-chunk limit above (e.g. a document with many chunks can add up past either even if each chunk alone is fine) — documents are sent to the embedding API in multiple requests to stay under both.

Chunks exceeding this are split further automatically right before embedding — local models here typically cap around 512 tokens; OpenAI-compatible APIs often allow far more (e.g. 8191). Set 0 to disable this check.

MCP Server

Controls how AI clients (Claude Code, Claude Desktop, claude.ai) connect to this RAG over MCP.

Off = anyone with the URL can read the stored documents. claude.ai Custom Connectors require OAuth; Claude Desktop may also expect it over a remote URL even when it's off here.

MCP Users

Separate accounts for logging into the MCP OAuth flow — not the same as the web admin login.

API Tokens

Static Bearer tokens for clients that can't do the OAuth login redirect (e.g. AnythingLLM's custom-headers config). Shown only once at creation — copy it immediately.
